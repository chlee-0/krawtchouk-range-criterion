# Krawtchouk range-criterion checks

Exact-arithmetic verification for the cases

$$
(4,7,2,7) \qquad\text{and}\qquad (4,15,5,12)
$$

from *Integral zeros of Krawtchouk polynomials and quantum entanglement*.

The scripts check the rank conditions and the matrix sum-of-squares inequality used in the proof.

## Run

```bash
python verify_4727.py
python verify_415512.py
```
